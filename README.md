# Кизяк (Kizyac) — iOS Port

Официальный порт игры **«Кизяк: Измерения» (версия 3.2.0)** для iOS / iPadOS.

## Архитектура порта
- **Движок**: Swift + Apple WebKit (`WKWebView`).
- **Звук**: Нативный звуковой пул `AVAudioPlayer` с нулевой задержкой и вариацией высоты тона для всех 180+ звуковых эффектов и фоновой музыки.
- **Тактильная отдача (Haptics)**: Apple Taptic Engine (`UIImpactFeedbackGenerator`).
- **Сохранения**: Локальная песочница iOS (`Documents/kizyac_save.kzsave` + `UserDefaults`) с поддержкой экспорта через системный Share Sheet и импорта через Files.

---

## 🚀 Как собрать IPA в облаке (без Mac)
1. Сделайте `git push` в репозиторий GitHub.
2. Перейдите во вкладку **Actions** в репозитории на GitHub.
3. Дождитесь завершения сборки **Build iOS App (.ipa)** (~2-3 минуты).
4. В блоке **Artifacts** скачайте **`Kizyac-iOS-IPA`** — внутри будет готовый файл `Kizyac.ipa`.

---

## 📲 Как установить на iPhone / iPad (через Windows)
1. Установите **Sideloadly** (https://sideloadly.io).
2. Подключите iPhone к компьютеру кабелем USB.
3. Перетащите файл `Kizyac.ipa` в окно Sideloadly.
4. Введите свой Apple ID (бесплатный личный аккаунт) и нажмите **Start**.
5. На iPhone:
   - Включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика** (включить и перезагрузить).
   - Доверьте сертификат: **Настройки → Основные → VPN и управление устройством** → нажмите на свой Apple ID → **Доверять**.
6. Игра готова к запуску!

---

## 🍏 Сборка на Mac в Xcode
1. Откройте `Kizyac.xcodeproj` в Xcode.
2. В разделе **Signing & Capabilities** выберите вашу команду (*Personal Team*).
3. Выберите ваше устройство и нажмите **Run (▶)**.
